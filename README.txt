NorskStart PWA

Installation / Hosting:
1. Inhalt dieses ZIP-Archivs auf einen HTTPS-Webserver laden (z.B. GitHub Pages, Netlify, Cloudflare Pages).
2. Die URL auf dem iPhone in Safari öffnen.
3. Teilen > Zum Home-Bildschirm > Hinzufügen.

Wichtig: Service Worker funktionieren über HTTPS oder localhost. Ein direkt aus der Dateien-App geöffnetes index.html ist daher nicht vollständig als PWA installierbar.
