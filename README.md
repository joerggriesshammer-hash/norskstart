# NorskStart

Installierbare Progressive Web App zum Norwegischlernen auf dem iPhone.

## GitHub Pages

1. Neues Repository auf GitHub anlegen, z. B. `norskstart`.
2. Alle Dateien aus diesem Projekt in den `main`-Branch hochladen.
3. Unter **Settings > Pages** bei **Build and deployment** die Quelle **Deploy from a branch** wählen.
4. Branch **main** und Ordner **/(root)** wählen und speichern.
5. Nach dem Deployment die GitHub-Pages-Adresse in Safari öffnen.
6. Auf dem iPhone: **Teilen > Zum Home-Bildschirm > Hinzufügen**.

Die PWA verwendet ausschließlich relative Pfade und funktioniert deshalb auch unter einer GitHub-Pages-Projekt-URL wie `https://BENUTZERNAME.github.io/norskstart/`.
